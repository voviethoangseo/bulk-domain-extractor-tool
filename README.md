# Bulk Domain Extractor Tool

A simple, lightweight, and secure client-side web tool designed to extract clean domain names from unstructured text or a list of URLs. 

This tool runs entirely in your web browser, ensuring that your data remains private and is never uploaded to any external server.

## Features

- **Text Parsing:** Extract domains directly from a block of text containing mixed URLs, text, or HTML.
- **WWW Stripping:** Option to automatically remove the `www.` prefix from extracted domains.
- **Deduplication:** Option to filter out duplicate domains and return a unique list.
- **Client-Side Execution:** All processing is done locally in your browser.
- **One-Click Copy:** Easily copy the extracted results to your clipboard.

## File Structure

The repository contains the following files:
* `bulk-domain-extractor-tool.html`: The main version of the tool.
* `bulk-domain-extractor-tool-en.html`: The English-optimized version of the tool.

## How to Use

No installation or server setup is required. To use the tool:

1. Clone or download this repository to your local machine:
   ```bash
   git clone https://github.com/voviethoangseo/bulk-domain-extractor-tool.git
2. Open either bulk-domain-extractor-tool.html or bulk-domain-extractor-tool-en.html in any modern web browser (such as Chrome, Firefox, Safari, or Edge).
3. Paste your text or URL list into the Input Text box.
4. Select your preferred options (e.g., Remove "www." and Remove duplicates).
5. Click Extract Domains to process.
6. Click Copy Results to copy the clean list of domains to your clipboard.
